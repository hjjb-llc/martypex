# Martypex

Public issue tracker for [Martypex](https://martypex.caffeinatedmath.com/), an iOS and iPadOS editor that turns Typst and Markdown into PDFs on your device.

## Links

- [Documentation](https://martypex.caffeinatedmath.com/)
- [Support](https://martypex.caffeinatedmath.com/support)
- [Report an issue](https://github.com/hjjb-llc/martypex/issues/new/choose)

## Crash reports

If Martypex quits unexpectedly, it offers to send a report the next time it opens. You can also send one any time from **Settings > Diagnostics > Report a Problem**. Choose GitHub and Martypex opens the crash report form with your app version, device, and iOS version filled in, and copies the report so you can paste it.

Reports never include your documents, and Martypex removes file paths before it saves them. Anything you post here is public, so read the report before you submit it. For a private report, choose Email instead, or write to [support@caffeinatedmath.com](mailto:support@caffeinatedmath.com).
